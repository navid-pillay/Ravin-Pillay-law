# Ravin Pillay Law

Website for Ravin Pillay, Barrister & Solicitor, criminal defence lawyer in Toronto.

Pages: `index.html` (home, with the Lady Justice opening animation), `practice.html`, `about.html`, `contact.html`.
Shared styles are in `assets/styles.css`.

## Regenerating

- Pages share one header, built by `python3 tools/build_pages.py` (edit page content there, then re-run).
- The Lady Justice drawing is generated by
  `python3 tools/lady_justice_sketch.py assets/lady-justice.svg assets/lady-justice-data.js`.
  The SVG is the static fallback; the data file feeds the canvas animation in `assets/lady-justice.js`.
